# 布谷响铃音源试听（选型用）

本目录是「响铃音源升级」的选型与试听材料，**不参与 App 打包**：它不在 `app/` 模块内，Gradle 不会扫描，也不会进入 APK。

## 打开方式

双击 `index.html`（选型试听）或 `compare.html`（改前/改后对照）即可离线试听（音频全部在本目录内，用相对路径引用，不依赖网络）。OGG 在部分浏览器不支持时会自动回退到 `masters/*.wav`。

## 目录

- `index.html`：自包含试听页，按气质分组，含时长、许可、来源、通知音/循环响铃建议与两段式方案
- `compare.html`：**改前 / 改后**对照试听页，旧 `bugu_call.wav` vs 新 `alarm_notice` / `alarm_loop`，含循环开关与接缝听辨
- `audio/`：12 个候选 + 1 个现状对照，均为本地文件
- `masters/`：组合 A 的两条成品母带（OGG + 无损 WAV）与 `MASTERING.md`
- `LICENSES.md`：逐条许可记录（来源页、许可类型、作者、文件哈希、检索日期）

## 与现网代码的关系

- 响铃页播放的是 `app/src/main/res/raw/bugu_call.wav`（1.42 秒，单声道 44.1 kHz），`MediaPlayer.isLooping = true` 循环
- 通知渠道 `bugu_alarm_ring` 用的是**系统默认闹铃**（`RingtoneManager.TYPE_ALARM`），与上面的 wav 不是同一个音源
- 因此真机到点时，很可能是「系统闹铃 + 自带 wav」两路声音叠加，这也是本次要一并处理的问题

## 使用注意

1. 这里的 Mixkit 文件是官方 320 kbps 预览 MP3；正式发版请从页面直链下载原始 WAV 后再做母带处理。
2. 这里的 Freesound 文件是官方 HQ 预览 MP3（CC0）；正式发版建议登录后下载原始文件，避免二次转码损失。
3. **不要直接把候选文件拷进 `res/raw`**：需先裁掉首尾静音、做 150–300 ms 等功率交叉淡化、按响铃周期重排，否则循环接缝会有明显停顿或爆音。
4. 试听页里的「峰值/首尾静音/接缝」数据由 `afinfo` + 定点采样分析得出，用于快速筛选，不等于听感结论；最终以真机外放试听为准。
