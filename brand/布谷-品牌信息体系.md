# 布谷 BUGU · 品牌信息体系 v1.0

> 品牌工作文档 · 2026-10-29 · **文案口径修订：2026-11-05**
> 结论先行：**主品牌定为「布谷 BUGU」，保留吉祥物「咕咕」为 IP 名。品牌叙事保留「惦记」，UI 功能词统一用「提醒」**。
> 主 slogan 沿用现有资产「让每一份惦记，都有回音」，不做推翻；**这句 slogan 是唯一允许在 UI 中使用「惦记」的文案层**。

## 1. 定名与命名架构

### 1.1 主品牌：布谷 BUGU

定名理由（三条，均可对外讲述）：

1. **布谷鸟的叫声本身就是提醒**——「布谷」谐音「播谷」，古人是听着它催农时的。一只鸟叫了千年，只为提醒你「该做那件事了」。这和产品「准时唤你」的属性天然同构。
2. **名字即吉祥物**——咕咕就是布谷鸟，品牌名、IP 名、叫声三位一体，不需要解释成本。
3. **布谷鸟报时钟是最经典的「提醒装置」意象**——咕咕钟每整点探出头报时，可爱且准时，为后续图标、动效、铃声提供现成母题。

英文/拼音：**BUGU**（全大写用于 logo 与版本尾注；正文用「布谷」）。

已评估并弃用的备选（避免反复讨论）：念念 NIANNIAN（情感浓但有重名）、惦记 DIANJI（仅保留在品牌叙事与主 slogan，不再作产品语言）、回音 ECHO（科技冷感）、咕咕 GUGU（网络语境=鸽子=放鸽子，撞「可靠性」红线）。

### 1.2 命名架构（三层）

| 层级 | 名称 | 说明 | 状态 |

| 主品牌 | **布谷 BUGU** | 桌面名、商店名、所有对外场合 | ✅ 已落地（Manifest + 9 处文案） |

## 2. 定位与信息屋

### 2.1 角色定位句（对内校准用）

**「你手机里那只准时的布谷鸟。」**

布谷在用户生活中扮演的角色：一只会提醒你、也替别人提醒你的鸟。品类词不叫「待办」，叫**陪伴型提醒**——提醒是功能，陪伴是关系。

### 2.2 信息屋

- **屋顶（一句话价值）**：让每一份惦记，都有回音。
- **三根支柱**（每根产品都要有对应证据）：
  1. **绝不鸽的提醒** → 不鸽保证；核心功能全部免费（提醒、闹钟、看板、互相提醒，当前无付费项目）
  2. **温柔不催的陪伴** → 咕咕四情绪动效、温和催办（对应 P1「温和催办」需求）
  3. **有人提醒你** → 好友互相提醒（绑定码已交付）、陪伴页；指尖轻碰、长辈模式尚未交付，对外文案不承诺
- **受众**：主 = 独自生活、日程靠脑记会漏的年轻人；副 = 异地恋人 / 父母与子女（互相提醒场景，竞品调研显示这是 CATO 流失用户的外流方向）。

### 2.3 Slogan 体系

| 场景 | 文案 |

| 主 slogan（商店、启动页、关于页；唯一可用「惦记」的 UI 文案） | 让每一份惦记，都有回音 |
| 登录页副句 | 布谷布谷，有人提醒你 |
| 推送/提醒落款 | —— 提醒你的布谷 |

## 3. 品牌声音

### 3.1 四条声音特征

1. **像老朋友，不像客服**——竞品通病是 AI 人机感重；咕咕说话要有「在呢在呢～」这种活人感。
2. **永远不责备**——漏了就是漏了，不说「你已逾期」。催办要软（P1 温和催办需求）。
3. **说人话**——不堆「智能引擎」「全链路」这类词；一个功能一句话说清。
4. **敢承诺**——可靠性、免费、隐私，直接说，不加「可能」「尽力」。

### 3.2 Do / Don't（正例均取自现有文案）

| 场景 | Don't | Do |
|---|---|---|
| 催办 | 「你已逾期 3 次，请尽快处理！」 | 「这条提醒还在等你～要现在看吗？」 |
| 提醒触发 | 「您有一条待办提醒」 | 「布谷！到点啦——别忘了提醒你的人呀」 |
| 权限被拒 | 「权限不足，功能受限」 | 「已进入体验模式，随时可回来开启权限」 |
| 出错 | 「Error: 请求失败 (code 500)」 | 「咕咕没听到，再说一次？」 |
| 免费说明 | 「基础版免费，升级 Pro 解锁全部」 | 「提醒、闹钟、看板、互相提醒，当前全部免费」 |

### 3.3 写前三查

发布任何 UI 文案/推送前自查：① 像咕咕（老朋友）说的吗？② 有没有一丝责备？③ 敢不敢把这句承诺印在商店页？

## 4. 视觉方向

### 4.1 色彩（沿用现有代码 H.* 体系，原则：暖底 + 珊瑚主色 + 薄荷点缀）

- **主色**：珊瑚橙系（H.Coral / H.CoralLight）——只用于主按钮、选中态、咕咕关键情绪
- **辅色**：薄荷绿（H.Mint）——在线状态、成功、次要强调
- **底色**：暖米色画布（H.Canvas）——全 App 统一暖底，禁纯白底
- **禁用**：冷灰蓝科技色、强对比荧光色（会加重人机感）

### 4.2 图形与字体

- 图形语言：胶囊圆角、圆形头像、纯 Canvas 矢量咕咕（四情绪）、心形迸发
- 咕咕是唯一 IP：不再引入第二吉祥物；咕咕必须以四情绪之一出现，不做静态贴图
- 字体：现状系统字体可用；引入品牌字体时选圆润人文无衬线方向，数字用等宽数字（tnum 已在登录页启用）

### 4.3 动效原则（已落地，作为规范固话）

- 弹簧曲线优先（选中弹跳、勾选、情绪切换），时长 200–380ms
- 列表错峰入场（40–70ms 步进），关键元素可呼吸脉动（1.04–1.08，≥1.4s 周期）
- 一切动效服务于「这只鸟活着」，不做炫技转场

### 4.4 声音品牌

- **布谷铃**：默认提醒音 = 真实布谷鸟叫两声，全 App 唯一
- 咕咕语气词资产库：咕咕！/ 布谷布谷～ / 在呢在呢～ （仅此风格，禁「滴—您有新消息」式机械音）

### 4.5 Logo 方向（待设计稿）

- 形：咕咕侧影（圆身短喙翘尾）+ 「布谷」圆体字标；横排为主，独立鸟形为图标位
- 最小尺寸 24dp、四周留白 ≥ 鸟身高度 1/4（正式数值待设计稿定）
